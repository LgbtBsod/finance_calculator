# 🏦 Личный финансовый калькулятор

Десктопное приложение для планирования личного бюджета: расчёт зарплаты по
производственному календарю РФ, планирование расходов по группам, отпускные,
дни рождения, долги и аналитика.

Интерфейс — [Flet](https://flet.dev) (локальный сервер + вкладка браузера),
данные — локальный SQLite-файл `budget.db` рядом с приложением.

## 🚀 Запуск из исходников

### Windows
```bash
run.bat
```

### Linux / macOS
```bash
./run.sh
```

Либо вручную:
```bash
python -m venv venv
venv\Scripts\activate            # Windows  (source venv/bin/activate — *nix)
pip install -r requirements.txt
python main.py
```

Откроется вкладка браузера на `http://localhost:8420`.

## 📦 Сборка standalone-версии (.exe)

```bash
python build.py --clean
```

Результат — `dist/FinanceCalculator.exe` (Windows) / `dist/FinanceCalculator`
(Linux, macOS). `budget.db`, `logs/` и `version.txt` живут рядом с
исполняемым файлом и переживают авто-обновление.

## 🔄 Обновления

Собранная версия сама проверяет GitHub Releases при запуске (можно отключить
в «Настройки → Обновления») и предлагает скачать новую версию. Установка —
подмена бинарника на месте с бэкапом БД и откатом при ошибке
(см. [`updater.py`](updater.py)).

Релиз выпускается пушем тега `vX.Y.Z` — GitHub Actions
([`.github/workflows/build.yml`](.github/workflows/build.yml)) собирает
бинарники под три ОС и прикладывает их к релизу.

## 🗂️ Структура

| Путь | Назначение |
|------|-----------|
| `main.py` | Точка входа: логи, завершение отложенного обновления, запуск GUI |
| `paths.py` | Единственный резолвер путей (frozen vs исходники) |
| `config.py` | Настройки-константы и дефолты (pydantic-settings) |
| `models.py` | Иммутабельные модели, Enum'ы, Protocol'ы, TypedDict'ы |
| `database.py` | SQLite: схема, миграции, CRUD |
| `calculator.py` | Чистая бизнес-логика: зарплата, баланс, дни рождения |
| `prod_calendar.py` | Производственный календарь РФ (`work-calendar` + PDF-поправки) |
| `services.py` | Фасад `FinanceService` — единственная точка входа GUI к логике и БД |
| `updater.py` | Self-updater через GitHub Releases |
| `gui/` | Flet-интерфейс: `app.py` (навигация/тема) + `views/` (экраны) |
| `tests/` | pytest |

## 🧪 Разработка

```bash
pip install -r requirements-dev.txt
pytest -q
ruff check .
```

## 📊 Возможности

- 💰 Расчёт зарплаты: 3 метода распределения по половинам месяца
  (пропорционально, свои пропорции, по рабочим дням), налог, коэффициент,
  перенос дат выплат с выходных
- 📅 Расходы по группам с месячными лимитами, повторяющиеся расходы с датой
  окончания
- 🏖️ Отпускные с диапазоном дней (влияют на расчёт по рабочим дням)
- 🎂 Дни рождения: напоминания за 14 дней и авто-создание расходов на подарки
- 💳 Долги: платежи и прогноз погашения
- 📈 Аналитика: сумма за период, тренд по месяцам, разбивка по категориям
- 💾 Резервное копирование БД

# 💰 Личный финансовый калькулятор

**Python + Streamlit + SQLite + Plotly** — современное приложение для учёта личных финансов с расчётом зарплаты по производственному календарю РФ и интерактивной визуализацией данных.

![Python Version](https://img.shields.io/badge/python-3.10+-blue.svg)
![Streamlit](https://img.shields.io/badge/streamlit-1.40+-red.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Особенности

- 📊 **Интерактивные графики** на базе Plotly с возможностью переключения на нативные виджеты Streamlit
- 📅 **Производственный календарь РФ** с автоматическим учётом правительственных переносов
- 💼 **Расчёт зарплаты** с учётом аванса, получки, отпускных и коэффициентов
- 💸 **Управление расходами** с поддержкой повторяющихся платежей
- 🎂 **Напоминания о днях рождения** с автоматическим созданием расходов на подарки
- 📈 **Годовая аналитика** с детальной визуализацией доходов, расходов и баланса
- 💾 **Локальное хранение** данных в SQLite с WAL-режимом для производительности

## 🏗️ Архитектура проекта

```
finance-calculator/
├── app.py              # Точка входа: инициализация сервисов, routing
├── calculator.py       # Бизнес-логика: SalaryCalculator, BirthdayService
├── config.py           # Константы, настройки по умолчанию
├── database.py         # DatabaseManager: все SQL-операции
├── models.py           # TypedDict, Protocol, frozen dataclass
├── prod_calendar.py    # CalendarProvider: Strategy + Decorator pattern
├── requirements.txt    # Зависимости проекта
├── run.bat            # Скрипт запуска для Windows
└── views/             # UI-компоненты (Single Responsibility Principle)
    ├── __init__.py
    ├── balance_tab.py      # Вкладка «Баланс и ЗП»
    ├── birthdays_tab.py    # Вкладка «Дни рождения»
    ├── charts_tab.py       # Вкладка «Визуализация» (Plotly)
    ├── common.py           # Общие хелперы
    ├── expenses_tab.py     # Вкладка «Расходы»
    ├── memo_tab.py         # Вкладка «Памятка»
    └── sidebar.py          # Боковая панель настроек
```

## 🚀 Быстрый старт

### Требования

- Python 3.10 или выше
- pip (менеджер пакетов Python)

### Установка

```bash
# Клонируйте репозиторий или перейдите в директорию проекта
cd finance-calculator

# Установите зависимости
pip install -r requirements.txt
```

### Запуск

#### Linux / macOS
```bash
streamlit run app.py
```

#### Windows
Двойной клик на `run.bat` или:
```cmd
streamlit run app.py
```

Приложение откроется в браузере по адресу **http://localhost:8501**

## 📋 Функциональные возможности

### 1. Баланс и ЗП 💰
- Расчёт чистой зарплаты после НДФЛ (13%)
- Пропорциональное распределение по половинам месяца
- Учёт производственного календаря (рабочие/выходные дни)
- Добавление отпускных к соответствующей половине месяца
- Настройка коэффициента эффективности (КЭФ)

### 2. Расходы 💸
- Добавление/удаление/редактирование расходов
- Распределение по половинам месяца (1-я/2-я)
- Повторяющиеся расходы (ежемесячные)
- Фильтрация по периоду

### 3. Дни рождения 🎂
- Хранение дат рождения контактов
- Триггер напоминания за 14 дней до события
- Автоматическое создание расходов на подарки
- Настройка суммы подарка для каждого контакта

### 4. Памятка 📝
- Список планируемых расходов (не влияют на баланс)
- Целевые даты для крупных покупок
- Заметки и напоминания

### 5. Визуализация 📊
- **Интерактивные графики Plotly** с зумом и детализацией
- Годовое распределение зарплаты (аванс/получка/чистая)
- Динамика расходов по месяцам
- Тренд остатков (положительный/отрицательный баланс)
- Сводная диаграмма: Доходы vs Расходы vs Баланс
- Переключение между Plotly и нативными виджетами Streamlit

## ⚙️ Настройки

Все настройки хранятся в SQLite (`budget.db`). Значения по умолчанию:

| Параметр | Значение | Описание |
|----------|----------|----------|
| **Оклад** | 100 000 ₽ | Месячная зарплата до вычета налогов |
| **НДФЛ** | 13% | Ставка подоходного налога |
| **КЭФ** | 1.0 | Коэффициент эффективности (премии/штрафы) |
| **День отсечки аванса** | 15 | Число месяца для разделения на половины |
| **Учитывать сокращённые дни** | Нет | Влияние коротких дней на расчёт |

## 📅 Производственный календарь

Используется библиотека [`work-calendar`](https://pypi.org/project/work-calendar/) с официальными данными с **consultant.ru**.

- ✅ Покрыты годы: **2015–2027+**
- ✅ Все правительственные переносы выходных дней учтены автоматически
- ✅ Предпраздничные сокращённые дни определяются автоматически

### Опциональная загрузка PDF
Для верификации данных или работы с годами вне диапазона можно загрузить PDF с consultant.ru:
```bash
pip install pdfplumber
```

## 🔧 Расширение функционала

### Добавление новой вкладки
1. Создайте файл `views/new_tab.py`
2. Реализуйте функцию `render_new_tab(...)`
3. Импортируйте в `app.py` и добавьте в `st.tabs()`

### Интеграция с внешними API
Модуль `database.py` использует Dependency Injection через Protocol — легко заменить SQLite на PostgreSQL или внешний API.

## 👨‍💻 Авторы

Разработано с использованием современных паттернов проектирования:
- **Strategy Pattern** — для провайдеров календаря
- **Decorator Pattern** — для корректировок календаря
- **Dependency Injection** — через Protocol для тестируемости
- **Single Responsibility Principle** — каждый модуль отвечает за одну задачу
- **Immutable Data Models** — frozen dataclasses для безопасности

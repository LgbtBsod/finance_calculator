# Изменения

## 3.0.0

Крупный релиз: переход с FastAPI+React на standalone Flet, модульная
архитектура через ядро, редизайн под SAP Horizon и большой пласт правок по
аудиту.

### Архитектура
- Standalone Flet вместо FastAPI+React; модульное ядро (`core/` + `modules/`),
  модули общаются только через Kernel, изоляция проверяется AST-тестом.
- `services.FinanceService` — единственный фасад GUI поверх ядра.
- Единый источник настроек `config.SETTINGS` (seed + чтение + запись).
- SSOT названий месяцев; порядок init/shutdown ядра — топосорт по `requires`.
- Потокобезопасность ядра (per-thread контекст запроса).

### Зарплата и расчёты
- Зарплата — сущность «доход» (`income.kind='salary'`): оклад/КЕФ/метод/
  пропорции на самой записи; **несколько работ** суммируются.
- Отпуск урезает оклад пропорционально отработанным дням (ТК РФ) для всех
  методов; граница половины месяца — по дню отсечения аванса.
- Прогрессивный НДФЛ 2025 (опция) — предельный налог месяца по годовому
  накоплению.
- Плановый платёж по долгу вычитается только за «живые» месяцы.

### Данные и надёжность
- БД в подпапке `db/` + автомиграция со старой раскладки.
- Отмена удаления (undo) вместо безвозвратного DELETE.
- Сумма повтора на один месяц (`period_overrides`).
- Строгий формат `recurring_until`; `backup_to` закрывает соединение.
- Диапазонные запросы к календарю вместо `LIKE` (индекс).
- Проекция повторяющихся строк помечается `projected`; правка/удаление
  проекции безопасны.
- Ошибка на экране не роняет приложение (error boundary во вью).

### Интерфейс
- Тема **SAP Horizon** (Morning / Evening) — палитра 1-в-1 из
  `@sap-theming/theming-base-content`, радиусы и тени Horizon.
- Fiori-стиль навигации; поля/кнопки/чипы/пустые состояния переоформлены.
- Сохранение позиции прокрутки при перестройке экрана.
- «Доходы» — отдельная форма зарплаты; «Настройки» без окладных полей.

### Аналитика и экспорт
- Тренд доход/расходы (кэшфлоу) с «чистыми» по месяцам.
- «Изменение к прошлому месяцу» по категориям.
- Аналитика «за всё время» с разворотом повторов.
- Экспорт всех записей в CSV (Excel/Google Таблицы).
- Предупреждение о превышении лимита группы на «Балансе».

### Сборка и обновления
- Сборка на CI под три ОС, `version.txt` сверяется с тегом.
- Апдейтер сверяет SHA256 бинарника с суммой из релиза, бэкапит `db/`.
- `requirements.txt` — единый список зависимостей, flet пиним точно.
- `scripts/launch.py` — гейт синхронизации зависимостей (раз в сутки) + таймаут.
